The Hono application is reusable. Node must keep these contracts, not serve only a blank SPA shell.

Keep worker sources and ten D1 migrations intact. Add a narrow PostgreSQL adapter for the SQL dialect actually used: bound placeholders, INSERT OR IGNORE, JSON array iteration, json_set and UTC date functions. Convert and check in all ten PostgreSQL migrations. Keep JSON/timestamps as compatible text, integer boolean flags and millisecond session expiry semantics; PostgreSQL bigint decoding must reject unsafe integers. Batch calls must use one client/transaction. Concurrent upserts, idempotency and gallery CAS are essential. A successful adapter query does not establish data-import compatibility for an existing live D1 database.

Add Node 24 entry point, bounded pooling, separate checksum/advisory-lock forward migration runner, liveness/readiness and private metrics. Use one configured PUBLIC_ORIGIN for CSRF/canonical URLs, HTTPS in production. Reuse existing signed HttpOnly/SameSite sessions, production Secure cookies, PBKDF2, server validation, auth and PII-safe errors.

Media drivers: durable local filesystem for one-replica lab and private S3-compatible storage for production; same DB publication/cleanup rules, no public bucket or client credentials. Filesystem must reject traversal/symlinks and use atomic writes. S3 needs approved bucket/IAM/TLS and independent live validation. Never import real customer records into tests or expose media storage directories through Nginx.

Docker/Compose must use isolated local project resources, no existing EC2/Jenkins/container changes. Default frontend host port remains 8081, Jenkins 8080 untouched, Kubernetes forwarding documented at 8090. PostgreSQL has no public port in supplied deployment configs. Lab PostgreSQL StatefulSet is not a production HA/backup design. Production requires approved managed database/storage/TLS/backup/restore and resource sizing. Jenkins and ArgoCD deployment ownership must be mutually exclusive. Terraform is preparation only: any EC2/EBS/S3 can incur costs, no apply or implicit NAT/LB.
