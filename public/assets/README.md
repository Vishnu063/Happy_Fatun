# Original demo illustrations

The 18 SVG images in this directory were authored for this project. They are simple vector furniture concepts, not photographs, representations of manufactured stock, or accurate product geometry. Each category shares its illustrations across four demo designs.

Views: `0` = clean background, `1` = room scene, `2` = alternative illustration. Replace with manufacturer-approved assets before representing real products. Product gallery order is editable in the owner studio. No third-party stock image license is required for these original illustrations.
