This is a point-in-time HIGH/CRITICAL policy result, not proof of zero vulnerabilities at all severities or future security. ## Failures exercised and fixes

- PostgreSQL rejected SQLite's ambiguous upsert columns and JSON comma-join scoping: qualified columns and used lateral JSON joins; real API tests now pass.
- Null-safe price audit comparisons required `IS DISTINCT FROM`; actual edit/NULL/no-change transitions now pass without leaking supplier costs.
- PostgreSQL temporary Unix-only startup readiness caused fixture races: wait for the final TCP listener before migrating/testing.
- Wrong Nginx config ownership, proxy-aware health checks, internal-only published network and independent CSS build hashing caused actual container failures: fixed ownership, loopback health command, frontend-only edge bridge and scoped Tailwind scanning; final full smoke passes.
- Malformed credential-bearing configuration URLs are redacted; filesystem traversal/symlink escapes, batch errors, auth/CSRF failures, checksum drift, partial migration failure, provider failures and spoofed proxy chains are covered by tests.
- Managed Docker uses `vfs` and exhausted its 32-GB workspace while retaining repeated build snapshots. Removed only identified task-owned unused artifacts, moved disposable dependency/provider caches to `/tmp`, and repeated affected checks. No existing workload was interrupted and no global prune was used. An 8-GB RAM requirement does not imply that this build fits an 8-GB disk.
