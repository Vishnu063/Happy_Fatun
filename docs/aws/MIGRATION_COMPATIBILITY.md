# D1 → PostgreSQL compatibility report

Original ten files remain in `migrations/`; checked-in counterparts are `migrations/postgres/`. `scripts/convert-postgres-migrations.mjs` is a deterministic local file conversion, never a database client. Runtime SQL compatibility is deliberately scoped to existing trusted Hono queries; it is not a general SQLite engine. New dialect constructs require explicit review/tests.

| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0001 initial         | Tables, PKs/FKs, indexes, 24 original demo rows and categories; BIGINT for SQLite 64-bit integer semantics, double precision dimensions, JSON text and UTC timestamp text |
| 0002 product media   | Registry, unique storage key, product FK cascade and lookup index                                                                                                         |
| 0003 owner sessions  | BIGINT millisecond expiry and index; safe JS numeric decoding preserves revocation/expiry comparisons                                                                     |

| 0008 SEO             | Optional metadata, alt-text compound key and cascading product relationship                                                                                               |

| 0010 sourcing        | Normalized private shops/links, FK restrictions, unique shop/product pair, optional costs/contacts, constraints/indexes                                                   |

All fresh seed product/category/settings values are independently compared against an in-memory database built from the original SQLite migrations (only generated timestamps excluded). Real PostgreSQL tests verify all ten apply, repeated application returns zero, concurrent runners serialize, modified checksums fail, a deliberate DDL error rolls back the whole file and resumes from the previous committed migration without resetting 29 seeded products. API tests cover private costs, duplicate races, rollback, auth/cookies, quote retries/PII erasure, JSON gallery iteration/media cleanup, SEO and Node HTTP proxy/readiness failures.

The adapter uses PostgreSQL `$n` parameters without substituting values, respects quoted question marks/comments, maps D1 results/changes/first/all and executes batch operations on one transaction client. JSON arrays become lateral `jsonb_array_elements_text(... WITH ORDINALITY)` over TEXT JSON; ordinals remain zero-based for gallery alt positions. The specific JSON notes update uses jsonb_set then returns text. UTC date arithmetic keeps legacy textual date ordering. Null-safe SQLite `IS NOT ?` price-audit comparisons map to `IS DISTINCT FROM`, with repeated unchanged prices producing no extra audit. PostgreSQL upsert references are qualified to avoid SQLite's looser ambiguity/join scope rules.

Important limits: PostgreSQL primary keys reject NULL where SQLite TEXT primary keys can be more permissive; validate legacy data before import. `INSERT OR IGNORE` maps to duplicate-conflict ignoring, not silent suppression of invalid CHECK/NOT NULL data. Database identifiers and normal FK/business rules remain stricter, never disabled. Unicode collation can differ; approved real multilingual catalogs require review. Integers outside JavaScript's safe range fail closed. The app role should not have migration/DDL permissions in production.

**No existing live D1 or PostgreSQL data was exported/imported or modified.** Fresh PostgreSQL compatibility is verified; real data cutover is not. Before approval: take a private owner-authorized snapshot, inventory rows/types/NULL IDs/JSON/dates/storage keys, map tables in FK order, rehearse import into an isolated shadow database, compare row counts/checksums/product prices/quote snapshots/sessions and storage objects, test restore and cutover/rollback. Preserve old D1/R2 throughout. Do not point test runners at production, use destructive seed resets, drop legacy tables or claim the live database was migrated.
